
# Weather App

A responsive weather application built with HTML, CSS, and JavaScript, powered by the OpenWeatherMap API. It allows users to search for a city and retrieve its current weather information.

## Live Demo

[View Live Application](https://vyronevra-dev.github.io/weather-app/)

## Features

- Search for weather information by city name.
- Display the current temperature.
- Display humidity percentage.
- Display wind speed.
- Retrieve real-time weather data using the OpenWeatherMap API.
- Simple and responsive user interface.

## Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application functionality and API integration.
- **OpenWeatherMap API** – Weather data provider.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Vyronevra-dev/weather-app.git
```

### Navigate to the Project Directory

```bash
cd weather-app
```

### Run the Application

Open `index.html` in your preferred web browser.

## API Integration

This application uses the [OpenWeatherMap API](https://openweathermap.org/api) to retrieve weather information based on the city entered by the user.
